# Bright Arcade UI Reference Set

Chosen direction: bright, cute, arcade-readable mahjong UI inspired by current Japanese online mahjong client layout patterns, adapted for Hong Kong 16-tile mahjong and cha chaan teng flavor.

Use these as visual references only. They are not production UI specs and should not be treated as exact generated assets.

## Files

- `01-home-landing.png` - main home screen with primary mode choices.
- `02-room-setup-wizard.png` - room creation wizard with presets, toggles, and live summary.
- `03-room-lobby.png` - private room lobby with seats, room code, QR/share, and ready states.
- `04-gameplay-table.png` - landscape four-player gameplay table.
- `05-claim-window.png` - gameplay table with claim/action window.
- `06-win-settlement.png` - win result, fan rows, count-up, settlement, and la ledger.
- `07-fan-table-editor.png` - FanTable editor with rows, steppers, toggles, and sample-hand preview.
- `08-rules-encyclopedia.png` - rules and fan encyclopedia with example hand cards.

## Style Anchors

- Bright cream and ivory surfaces.
- Light jade/mint panels and table felt.
- Coral red, jade green, brass gold, and pale blue action accents.
- Charcoal reserved for text, thin icons, and outlines.
- Cute food-themed avatar badges.
- Strict mahjong-client information layout: readability before decoration.
